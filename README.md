# 💸 Paytm Clone - Frontend Project

This is a fun frontend-only project inspired by the Paytm homepage. It is built using **HTML** and **CSS** and aims to replicate the look and feel of the Paytm website. The project is a part of my learning journey as I improve my web development skills.

## 🚀 Features

* Responsive design mimicking Paytm’s homepage layout
* Clean HTML structure
* Custom CSS styling for layout, buttons, cards, and hover effects
* Organized file structure
* No JavaScript – purely HTML & CSS!
